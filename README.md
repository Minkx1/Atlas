# Newt

**Newt** is a voice assistant written in Python, that shall give you a completely NEW Talk with your piece of scrap some would call a PC.

## Installation

### Prerequisites

- Python 3.10 or higher.
- Git.

If you meet all  prerequisites, then to install:
* On Windows: Double-click `install.bat` or run it in the terminal.
* On Linux: Run `bash install.sh`.

And then run
```shell
python main.py
```
